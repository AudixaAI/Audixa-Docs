Audixa uses paid, plan-based generation. There are no free generations or trial
credits. You can listen to fixed samples at
[audixa.ai/voices](https://audixa.ai/voices) without creating audio.

## Enable Generation

Choose one of these options before generating through the dashboard or API:

- Purchase a top-up of at least **$10**.
- Start a subscription that includes a monthly generation balance.

See [audixa.ai/pricing](https://audixa.ai/pricing) for the currently available
plans, balances, rates, limits, and commercial terms. The pricing page and your
authenticated billing dashboard are the source of truth; this guide does not
duplicate a static price matrix.

## How Generation Cost Works

The server calculates each accepted request from:

1. The submitted text length, represented as billable tokens.
2. The selected model: `base` or `advanced`.
3. The per-token rate attached to your active plan.

Short text is accepted from 1 character. TTS billing uses
`ceil(max(30, character_count) / 4)`, with a minimum charge of **8 tokens** per
generation. This applies to standard, dedicated, and streaming TTS, and to each
message in a conversation before the existing conversation multiplier. For
example, `Hi!` and a 30-character sentence both cost 8 tokens at your plan's
model rate; 100 characters cost 25 tokens. The minimum affects billing only;
Audixa generates the submitted text without padding it.

The create-generation response includes `tokens` and `dollar_cost`. Audixa
reserves the required balance when the request is accepted and restores the
reserved amount if processing fails.

<Note>
  Text length is not a guaranteed audio duration. Speaking speed, language,
  punctuation, voice, and model can all affect the final duration.
</Note>

## Billing Order

When both balances are available, Audixa uses:

1. **Monthly balance** included with the subscription.
2. **Top-up balance** purchased separately.

Monthly balance resets on the subscription billing cycle and unused monthly
funds do not roll over.

## Top-Up Expiry

Top-up expiry depends on subscription status:

- While a subscription is active, the expiry clock for remaining top-up grants
  is paused.
- Without an active subscription, remaining top-up grants expire after **30
  days**. This applies to top-ups purchased without a subscription and to funds
  remaining after a subscription ends.
- Starting a subscription again pauses the clock on active, unexpired grants.

The Billing page displays the current expiry state and the next applicable
expiry date returned by the backend.

## Checking Your Balance

Open [Dashboard → Billing](https://audixa.ai/app/billing) to review monthly and
top-up balances, current plan facts, payments, and generation charges.

## Insufficient Balance

If the available monthly and top-up balances cannot cover the request, the API
returns `402 Payment Required` and does not queue the generation.

<ResponseExample>
```json 402 Payment Required
{
  "detail": "Insufficient balance. Cost: $0.0120, wallet: $0.00, topup: $0.00"
}
```
</ResponseExample>

Handle the HTTP status directly rather than depending on an Audixa-specific SDK:

<CodeGroup>
```python Python
response = requests.post(API_URL, headers=headers, json=payload, timeout=30)

if response.status_code == 402:
    raise RuntimeError("Insufficient balance; open https://audixa.ai/app/billing")

response.raise_for_status()
```

```javascript JavaScript
const response = await fetch(API_URL, {
  method: 'POST',
  headers,
  body: JSON.stringify(payload)
});

if (response.status === 402) {
  throw new Error('Insufficient balance; open https://audixa.ai/app/billing');
}

if (!response.ok) throw new Error(await response.text());
```
</CodeGroup>
