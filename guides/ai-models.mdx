---
title: "AI Models"
description: "Compare the request controls and voice compatibility of Base and Advanced"
---

Audixa accepts `base` and `advanced` as the TTS `model`. Model selection changes
the compatible voice set, language-code scheme, controls, and plan rate. It does
not override the requirement that `voice_id` must match the selected model.

## Base Model

Base requests support:

- Base-compatible system voices returned by `GET /v3/voices?model=base`.
- `speed` from `0.5` to `2.0`.
- Single-letter `language_code` values.
- `wav` or `mp3` output.

```json
{
  "text": "This Base request demonstrates the documented delivery controls.",
  "voice_id": "am_ethan",
  "model": "base",
  "speed": 1.1,
  "language_code": "a",
  "audio_format": "mp3"
}
```

## Advanced Model

Advanced requests support:

- Advanced-compatible system and account-owned custom voices.
- `cfg_weight` from `1.0` to `5.0`.
- `exaggeration` from `0.0` to `1.0`.
- Advanced model language codes such as `en`, `de`, or `ja`.
- `wav` or `mp3` output.

```json
{
  "text": "This Advanced request demonstrates its two guidance controls.",
  "voice_id": "YOUR_ADVANCED_VOICE_ID",
  "model": "advanced",
  "cfg_weight": 3.5,
  "exaggeration": 0.7,
  "language_code": "en",
  "audio_format": "mp3"
}
```

## Side-by-Side Contract

| Capability | Base | Advanced |
|---|---|---|
| Request value | `model: "base"` | `model: "advanced"` |
| Delivery controls | `speed` | `cfg_weight`, `exaggeration` |
| Language codes | Single-letter scheme | Model-supported ISO-style codes |
| Audio formats | `wav`, `mp3` | `wav`, `mp3` |
| Compatible voices | Base voices | Advanced and compatible custom voices |
| Rate and text limit | Set by current plan | Set by current plan |

## Choose a Model

1. List voices for the intended model.
2. Select a returned `voice_id`.
3. Use only controls accepted for that model.
4. Review the current rate and limits in
   [Billing](https://audixa.ai/app/billing) or on
   [Pricing](https://audixa.ai/pricing).

<Warning>
  A Base voice cannot be used with `model: "advanced"`, and an Advanced voice
  cannot be used with `model: "base"`. The API rejects mismatched requests.
</Warning>
