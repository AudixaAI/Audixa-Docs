Track updates, new features, and improvements to the Audixa API.

<Update label="December 2024" description="v2.1.0">
  ### New Features
  - Added `cfg_weight` and `exaggeration` parameters for Advanced model voices
  - Support for expressiveness controls on Advanced model
  - New British English voices: Luna, Atlas
  
  ### Improvements
  - Better error messages with field-level validation
</Update>

<Update label="November 2024" description="v2.0.0">
  ### Breaking Changes
  - API version upgraded to v2 (`/v2/` prefix)
  - Added `X-API-Key` authentication alongside Bearer authentication
  
  ### New Features
  - Async workflow with `POST /tts` and `GET /tts?generation_id=...`
  - Voice cloning support in Advanced model
  - Speed control parameter (0.5x - 2.0x)
  
  ### Improvements
  - Added Base-compatible system voices
</Update>

<Update label="October 2024" description="v1.5.0">
  ### New Features
  - Added `/voices` endpoint to list available voices
  - Model parameter to choose between Base and Advanced
  
  ### Improvements
  - Expanded the voice library
</Update>

<Update label="September 2024" description="v1.0.0">
  ### Initial Release
  - Text-to-Speech API with multiple voice options
  - Paid wallet billing system
  - Dashboard for voice preview and testing
  - API key management
</Update>
